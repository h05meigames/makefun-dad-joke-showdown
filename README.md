One original dad joke — a guitar that frets, and a father who claims
fretting as his own job at the dinner table — written for the
[u-mfnakmal-dad-joke-showdown-1d2ce3e5](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5)
bounty on [make.fun](https://make.fun/r/0ene8b3q).

## The joke

> My daughter asked why the guitar never gets invited to dinner. I said, 'Because it always frets, and at this table, fretting is Dad's job.'

## How it works

`main.ts` (Node 22, standard library only) writes the joke to
`/output/entry.txt` — one joke, UTF-8, no trailing newline, 139 characters,
well within the 200-character limit.

## Run it

```sh
node main.ts
```
